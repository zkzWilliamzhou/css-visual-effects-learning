# css-visual-effects-learning

Interactive learning platform for CSS/JS visual effects.

## Why?

CSS and JavaScript visual effects are powerful but hard to learn. Most resources are static articles or videos. This platform makes learning interactive, gamified, and shareable.

## Features

- **Live preview**: Edit CSS/JS and see results instantly in the browser
- **Gamified progress**: Earn points, unlock levels as you master effects
- **Create & share**: Save your creations, share links with others
- **Interactive challenges**: Complete effect-building missions to level up
- **Community showcase**: Browse and remix other creators' effects
- **Responsive design**: Works on desktop and mobile

## Quick Start

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build
```
